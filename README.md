# Cursor CRM

CRM отдела продаж: Kanban заявок, оплаты, руководительский дашборд, помесячные планы, условия сотрудников и расчёт премий.

## Возможности

- роли руководителя и менеджеров;
- отдельные рабочие столы Алины и Паши;
- фильтры по менеджеру, тарифу и способу оплаты;
- сортировка таблицы оплат;
- перенос заявок между этапами Kanban;
- автоматическое создание оплаты из успешной сделки;
- планы и мотивация с историей по месяцам;
- нормализованная реляционная база Cloudflare D1;
- история смены статусов и журнал значимых изменений.

Подробная структура базы: [`docs/DATABASE_SCHEMA.md`](docs/DATABASE_SCHEMA.md).

## Тестовые пользователи

| Роль | Логин | Пароль |
|---|---|---|
| Руководитель | `admin@cursorcrm.ru` | `Admin2026!` |
| Алина | `manager@cursorcrm.ru` | `Manager2026!` |
| Паша | `pasha@cursorcrm.ru` | `Pasha2026!` |

Учётные записи предназначены для демонстрации. Перед рабочим использованием необходимо подключить серверную аутентификацию и заменить тестовые пароли.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
corepack enable
pnpm install
pnpm run db:generate
pnpm run dev
```

После запуска откройте `http://localhost:3000`.

## Сборка

```bash
pnpm run build
```

## Данные

Начальный набор для локальной демонстрации находится в `app/data/normalized.json`. При первом обращении API переносит его в нормализованные таблицы D1. Дальнейшие изменения интерфейса сохраняются в базе.
