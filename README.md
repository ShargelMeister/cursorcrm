# FinFlow CRM

CRM для отдела продаж: Kanban заявок, оплаты, руководительский дашборд, помесячные планы, условия сотрудников и расчёт премий.

## Возможности

- роли руководителя и менеджеров;
- отдельные рабочие столы Алины и Паши;
- фильтры по менеджеру, тарифу и способу оплаты;
- сортировка таблицы оплат;
- перенос заявок между этапами Kanban;
- автоматическое создание оплаты из успешной сделки;
- планы и мотивация с историей по месяцам;
- хранение изменённого состояния в Cloudflare D1 при публикации через OpenAI Sites.

## Тестовые пользователи

| Роль | Логин | Пароль |
|---|---|---|
| Руководитель | `admin@finflow.ru` | `Admin2026!` |
| Алина | `manager@finflow.ru` | `Manager2026!` |
| Паша | `pasha@finflow.ru` | `Pasha2026!` |

Эти учётные записи предназначены только для демонстрационной версии. Перед рабочим использованием необходимо подключить серверную аутентификацию и заменить тестовые пароли.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Сборка

```bash
npm run build
```

## Исходные данные

Нормализованный демонстрационный набор находится в `app/data/normalized.json`. Исходный Excel-файл намеренно не включён в публичный пакет, поскольку может содержать персональные данные клиентов.
